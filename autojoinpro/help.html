Auto Join Pro — Help

Version 1.0.0 · Autodesk® Revit® 2025, 2026, 2027

Auto Join Pro joins geometry and reports clashes across a whole model, a whole view, or a manual selection, with the join priority under your control.

Installation

  1. Close all running instances of Revit.
  2. Run the installer downloaded from the Autodesk App Store.
  3. Start Revit. A CYF tab appears on the ribbon with an Auto Join Pro panel containing two buttons: Batch Join and Clash Check.

The app is installed to %ProgramData%\Autodesk\ApplicationPlugins\Auto Join Pro.bundle.

The dialog

Both ribbon buttons open the same window; they differ only in which mode it starts in. The window is modeless, so you can keep it open while you work in the model.

Execution Scope

  • Project — every element in the model.
  • Active View — everything visible in the current view. This is the practical way to work storey by storey: open a view limited to one level and process just that.
  • Selection — the window hides and Revit asks you to pick elements. Only the categories in your priority list can be picked. Click Finish when done, or press Esc to cancel.

Action Mode

  • Join — joins intersecting elements and sets the cut order.
  • Clash Check — reports overlaps without modifying the model, then selects the affected elements so you can look at them.

Switching to Clash Check adds Stairs and Toposolids to the category list. These two are checked for overlaps but never joined, because Revit's native stairs and toposolids do not join reliably.

Categories and priority

Move the categories your project uses from Available into Priority (High → Low) using the arrow buttons, or by double-clicking an entry. Use the up and down buttons to rank them.

Whatever sits higher cuts whatever sits lower, and the same rule is applied at every junction in the batch. A structural model usually reads top to bottom as:

  1. Structural Columns
  2. Structural Framing
  3. Structural Foundations
  4. Floors
  5. Walls

Columns run full height and cut the beams that frame into them; beams cut the slabs they support; slabs cut the walls beneath. If your office's take-off convention differs, reorder the list to match it — and keep the same order for every run on a project, so the quantities stay comparable.

Recommended practice

  • Save before you run. The operation is undoable, but a saved file is a better safety net than the undo stack.
  • Work in batches. Active View scope on a single storey is easier to review than Project scope on a whole building, and far easier to undo if the result is not what you expected.
  • Run Clash Check before and after. Before, so you know what you are dealing with. After, so you can see what could not be resolved.

This changes your quantities

Joining changes how Revit assigns shared volume between elements. That is what joining is for — it removes the double-counting caused by overlapping solids. But it means the numbers in your schedules, and in any quantity take-off built on them, will be different afterwards.

This is expected behaviour, not a defect. Run the tool on a copy of the model first, note your schedule quantities before and after, and confirm the change is in the direction you expect. Auto Join Pro automates a repetitive operation consistently; it does not verify that the outcome is correct for your project.

Limitations

  • Elements Revit itself cannot join are skipped. The Join mode category list reflects this and offers fewer categories than Clash Check.
  • The tool operates on the current model only. Linked models are never modified.
  • Clash Check reports overlaps that are not joined. An overlap between two joined elements is treated as intentional and is not reported.
  • Large scopes take proportionally longer, and Revit is unresponsive while the operation runs. The elapsed time is shown when it finishes.

Uninstalling

Close Revit, then use Windows Settings → Apps → Installed apps, select Auto Join Pro and choose Uninstall. You can also remove it from the Autodesk App Manager. Uninstalling removes the bundle folder; your Revit models are not affected.
